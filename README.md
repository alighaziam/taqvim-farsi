# تقویم فارسی

پروژه اندروید تقویم فارسی؛ Kotlin، Jetpack Compose، Material 3، MVVM، Glance و WorkManager.

## دریافت سورس
فایل فشرده کامل پروژه در همین مخزن با نام `TaqvimFarsi-Android.zip` قرار می‌گیرد. پس از دانلود، آن را استخراج و پوشه `TaqvimFarsi` را در Android Studio باز کنید.

## وضعیت نسخه
این نسخه اسکلت اولیه قابل توسعه است. داده‌های مناسبت‌ها نمونه‌اند و باید با تقویم رسمی هر سال تطبیق داده شوند. آزمون‌ها و ساخت APK هنوز در محیط CI اجرا و تأیید نشده‌اند؛ `gradle-wrapper.jar` نیز در بسته نیست.
